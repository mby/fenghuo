# 监控与管理

[English](monitoring.md)

## 公开信息

设置中可分别控制匿名访客查看系统/硬件信息、到期日期、月流量/额度和 TCP 探测历史。
系统详情（含内核和 Agent 版本）与到期日期默认隐藏，月流量和探测默认公开。
限制在服务端 API 生效，不只是隐藏界面。管理端口的已登录管理员仍可查看全部数据。
资产字段、IP、凭据和私有备注始终不公开。隐藏系统详情时，匿名元数据也不返回服务端版本。
公开备注和探测名称属于用户填写的公开文字，请勿填写秘密信息。
关闭公开状态页总开关后，匿名访客无法读取任何节点数据。

## 网络监控与告警

有新鲜 TCP 探测样本时，节点卡片显示已选目标的简要摘要，最多三个；未配置探测的节点不增加空白区域。
节点详情同时展示 TCP 建连延迟和连接尝试失败比例，后者不等同 ICMP 丢包率。
本地目标最多 16 个；首页选择仅影响展示。网络历史默认最近 24 小时，近期使用分钟记录、
较早使用小时汇总，分别由 `-keep-minute-days`（默认 7 天）和 `-keep-hour-days`（默认 90 天）控制。
探测目标只能在 Agent 本地配置；告警中的可选目标按本地配置的名称匹配。
留空表示监控任一已上报目标，不会创建或修改 Agent 的探测目标。

网络历史按所选时间范围聚合为约 360 个点以内，图表据此判断数据空档；演示数据使用相同粒度，
覆盖完整查询时段。缺失记录保持断线，不补零；连接全部失败的时段只显示失败率，延迟保持未知。

首页卡片采用自然高度的紧凑分栏，公开说明收进名称旁的提示，标签放在底部。
点击首页卡片或列表行会在当前页面打开详情弹层，关闭、按 Esc 或浏览器后退会保留首页筛选、排序及滚动位置。
详情仍有独立链接，直接访问或使用“完整页面”入口可查看完整页面。
网络区展示最多三个目标的近五分钟平均延迟，悬浮可查看各目标失败率及计算口径。
下方延迟与失败率的平均值只合并当前展示的目标，分别按成功连接数与总尝试数加权。
短历史条每格 30 秒，可悬浮或使用键盘左右键查看该格数值和目标覆盖数；缺失格不补零。
它复用内存探测窗口，每目标最多 11 格，随节点响应返回并受公开探测开关保护，不新增数据库存储或请求。

延迟和失败率告警使用最近五分钟的内存探测窗口，达到或超过阈值并持续指定时间后触发，
低于阈值后恢复。延迟只计算成功样本；全部失败时，延迟视为未知，失败率为 100%。
超过两分钟没有新探测样本视为过期：中断待触发的持续计时，不发送恢复通知。
使用网络告警时，请将本地探测间隔设为明显小于两分钟（默认 30 秒）。
服务端重启会清空内存窗口，但保留已触发的告警状态。历史图仍沿用分钟聚合和现有保留策略。

## 通知发送

告警为当前启用的渠道创建持久化发送任务，由两个工作协程处理，同一渠道按顺序发送。
每条最多尝试五次，重试等待时间依次为 5 秒、30 秒、2 分钟、10 分钟。
待发送任务在服务端重启后继续处理，中断的发送租约可在一分钟后重试。
如果接收端已收到通知但确认响应丢失，重试可能造成重复消息，不提供严格的恰好一次投递。

队列最多容纳 1,000 条活跃任务；容量或持久化失败会记入日志，不无限增加协程或内存。
告警页面显示最近 100 条发送及尝试记录；已完成历史最多 5,000 条、保留七天。
禁用或删除渠道会取消待发送任务，已发出的请求仍可能到达接收端。重试使用渠道当前配置。
存储及展示的错误只使用固定代码，不含 URL、凭据或远端响应体。
原有“发送测试”仍是直接测试，不进入告警发送历史。

## 可用率与故障时间线

节点详情提供 7、30、90 天视图。后台每分钟观察节点状态，只有相邻、状态一致且间距不超过
90 秒的已知观察才贡献已知时长。可用率为在线 /（在线 + 离线），覆盖率为已知时长 / 完整查询窗口。
没有已知时长时，不显示可用率百分比。

启动、从未上报、状态切换、服务端停机、观察延迟和持久化失败都会保留明确的未知空档，
最新尚未完成的区间也为未知。两次观察之间的短暂中断可能遗漏。
这是面板视角的采样估算，不代表业务服务一定可达。故障次数统计已观察到的离线区间；
未知空档会分隔区间，不证明节点曾恢复。时间线显示最近 100 个区间，汇总仍覆盖完整时间范围。
记录保留 91 天，相邻同状态区间合并；删除节点会删除对应可用性历史。

## 资产与对比

节点编辑器记录私有的供应商、地区、标签、价格、币种、账期和自动续费备注。
自动续费仅为记录，不触发续费或付款。费用按价格除以账期月数估算，各币种独立汇总，不做汇率换算。
所有填写价格的节点均参与，包括隐藏、已到期和离线节点；零价及未定价节点不参与。
月度、年度金额为四舍五入后的估算，不是账单。

公开首页支持搜索名称、分组、公开标签和公开备注，管理库存搜索还包含私有资产字段。
排序对缺失和隐藏数据作单独处理。最多选择四个可见节点，按时间对齐对比实时或历史数据。
分享链接只记录节点和时间范围，不授予额外权限，也不会公开隐藏节点。

## 节点卡片与公开标签

卡片把核心数和总内存压缩在系统信息行，例如 `Debian 13 / amd64 / 2C4G / kvm`，不单列配置块。
磁盘容量不在该行重复展示。在线时显示 CPU 使用率、内存/磁盘已用与总量、
上下行网速和运行时间。离线后收起实时使用指标，保留最近上报的配置及月度流量，不把未知网速当作 0。
总容量通过原有后台批处理保存，重启后仍可展示；配置缩写省略未知值，等待 Agent 再次上报后补齐。
缓存配置可能过时，并受“公开系统信息”控制；它不代表节点当前在线，也不持久化实时使用率。

在节点编辑器的“公开展示”中填写公开标签，用英文/中文逗号或换行分隔，最多 6 个、每个不超过 20 字。
它们会显示在卡片、列表和详情中，并参与公开搜索。标签只按文本渲染。
公开标签与私有资产标签独立，已有私有标签不会自动公开；公开备注用于简短说明，私密信息仍填入私有备注。

列表保留与卡片相同的配置、公开标签、备注、使用量、流量额度和到期信息。
告警单独展示，不再覆盖介绍；窄屏会把这些信息上下排布，避免挤在桌面表格列中。
在线节点的 CPU 栏还在使用率条下显示最近上报的 1/5/15 分钟平均负载。

在卡片或列表中，将鼠标移到流量额度或流量累计值上，可查看下次重置日期、时间及该时刻的服务器 UTC 偏移。
每个节点可设置 1–31 日重置；按购买日计费时，填写购买日期中的日数。重置按服务器时区的午夜计算。
当月没有对应日期时按月末重置，下个月仍沿用原设定日期。此处是本地流量统计的估算，应与供应商账期设置一致。
关闭公开流量后，重置时间也不会对匿名访客公开。

## 会话与审计

安全页面显示活跃会话的管理标识、创建/到期时间、IP、浏览器信息。
可撤销单个会话或其他全部会话；撤销当前会话会退出登录。不会返回会话 Token 或其哈希。

审计记录登录尝试和已认证的配置修改，包括密码/TOTP、节点/规则/渠道、Token 轮换和会话撤销。
仅保存白名单操作、校验过的目标 ID、时间、HTTP 状态及 IP，不保存请求体或秘密信息。
由后台任务写入，保留 30 天、最多 10,000 条，每页最多 100 条并支持游标分页。
队列容纳 1,024 条事件及 128 条待写入记录，溢出会计数并记日志。
进程崩溃可能丢失尚未落库的事件；本地审计不能抵御已控制服务端的攻击者篡改。

## 升级与验证

先升级服务端。新增迁移 002–006，不修改已发布的 001 迁移。
已有 Agent 保留本地间隔及其他配置，没有新增第三方依赖、监听端口、磁盘写入、命令或升级通道。
升级前备份数据库；旧版二进制不能安全使用新结构。

运行 `make check`。Windows 上依次运行 `go test ./...`、`go vet ./...`，并设置
`GOOS=linux CGO_ENABLED=0` 运行 Linux 目标的 `go vet ./...`；前端运行 `pnpm --dir web test`、
`pnpm --dir web lint`、`pnpm --dir web typecheck` 和 `pnpm --dir web build`。
