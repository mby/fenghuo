# Fenghuo v0.2.1

## 中文

本版修复 Docker 前端构建缺少探测配置脚本的问题，并包含 v0.2.0 的全部功能与安全修复：

CI 新增 Docker 前端阶段构建检查，提前发现容器构建上下文中的文件缺失。

- 新增非特权 ICMP 探测，每个目标可在本地选择 TCP、ICMP 或同时启用。后台预设生成的配置命令对两种协议使用同一个探测间隔，支持 15、30、60 秒。
- 首页逐目标展示延迟和丢包率/连接失败率。历史条固定 12 格铺满宽度，每格代表一个完整分钟，按服务端时间对齐；可读取已有分钟历史补齐服务重启后的记录，缺失采样保持未知。
- ICMP 与 TCP 分别记录历史，按实际尝试数和成功数汇总。探测上报支持有界重试队列与去重；已有 TCP 告警仍使用原来的五分钟评估窗口。
- 改进状态页布局与节点详情浏览，提供中英文界面和文档。
- 修复旧 TCP 调度器遗留代码导致的 Staticcheck 失败。
- 构建最低版本为 Go 1.27.4，修复标准库 `net/http` 漏洞 [GO-2026-6859](https://pkg.go.dev/vuln/GO-2026-6859)。

### 升级说明

1. 升级前备份 SQLite 数据库和本地配置。v0.2.x 新增探测历史的协议与计数迁移；回滚时需同时恢复旧二进制及匹配的数据库备份。
2. **先升级 Server，再升级 Agent**。旧 Server 不识别新版 Agent 的探测上报字段。
3. 探测配置仍需在每台 Agent 主机本地应用；后台保存预设不会远程修改 Agent。Linux ICMP 使用非特权 ping socket，需由系统的 `net.ipv4.ping_group_range` 允许服务用户组。

## English

This patch includes the probe configuration script in the Docker frontend build stage, and includes all v0.2.0 features and security fixes:

CI now builds the Docker frontend stage to catch missing build-context files before release.

- Add unprivileged ICMP probes with locally selected TCP, ICMP or both per target. Generated preset commands share one interval across both protocols: 15, 30 or 60 seconds.
- Show per-target latency and packet loss/connection failure rates. Card strips fill their width with 12 complete one-minute cells aligned to server time. Available stored minute history fills restart gaps; missing measurements remain unknown.
- Keep TCP and ICMP history separate and aggregate actual attempt and success counts. Bounded retry queues and deduplication improve sample delivery. Existing TCP alerts retain their five-minute evaluation window.
- Improve status-page layout and node-detail navigation, with bilingual UI and documentation.
- Remove the obsolete TCP scheduler that caused Staticcheck to fail.
- Require Go 1.27.4 or newer to fix standard-library `net/http` vulnerability [GO-2026-6859](https://pkg.go.dev/vuln/GO-2026-6859).

### Upgrading

1. Back up SQLite and local configuration first. v0.2.x migrates probe history to include protocol and counts; rollback requires the previous binary and its matching database backup.
2. **Upgrade Server before Agent.** Older servers reject the new agent report fields.
3. Apply probe configuration locally on each agent host. Saving an admin preset does not remotely configure agents. Linux ICMP uses unprivileged ping sockets; `net.ipv4.ping_group_range` must permit the service group.
